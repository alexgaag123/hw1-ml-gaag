# Предсказание стоимости автомобилей

Цель работы: обучить линейную модель для предсказания selling_price и оценить её качество по статистическим и бизнес-метрикам.

## 1. Исследование и подготовка данных

Проверены размеры выборок, пропуски, дубликаты и основные статистики. Из train удалены повторяющиеся объекты с одинаковыми признаками. После удаления осталось 5840 строк, размер test составил 1000 строк.

Из mileage, engine и max_power удалены единицы измерения, значения преобразованы в числа. Из torque выделены крутящий момент и обороты. Значения момента в кгс·м переведены в Н·м.

Пропуски заполнены медианами train. Эти же медианы использованы для test. engine и seats приведены к целочисленному типу.

Построены графики распределений и попарных зависимостей, рассчитаны корреляции Пирсона, Спирмена и PhiK. Для изучения крайних значений использованы ящики с усами, для оценки формы распределений построены гистограммы.

## 2. Модели на числовых признаках

Обучена обычная линейная регрессия. Затем были проверены регрессия с стандартизацией, Lasso, ElasticNet и L0-регуляризация. Для Lasso и ElasticNet выполнен подбор гиперпараметров с кросс-валидацией.

Результаты на test:

| Модель | R² | MSE |
|---|---:|---:|
| LinearRegression | 0,6007 | 2,2950e11 |
| Lasso | 0,6007 | 2,2950e11 |
| Lasso с подбором параметров | 0,5994 | 2,3026e11 |
| ElasticNet с подбором параметров | 0,5994 | 2,3026e11 |
| L0 при lambda=1e8 | 0,6007 | 2,2955e11 |

Обычная линейная регрессия объяснила около 60% разброса цены на тестовой выборке. Все модели дали практически одинаковый результат.

## 3. Добавление категориальных признаков

Из name выделена марка автомобиля. Марка, fuel, seller_type, transmission, owner и seats закодированы через OneHotEncoder.

Энкодер и скейлер включены в пайплайн с Ridge. Параметр alpha подобран через GridSearchCV с 10 фолдами. Лучшее значение составило 1000.

На test получены R²=0,7761 и MSE=1,2869e11. Добавление категориальных признаков улучшило прогноз: R² вырос с 0,6007 до 0,7761.

## 4. Feature Engineering и обработка выбросов

Из исходного name дополнительно выделен model_name, чтобы различать модели автомобилей одной марки.

Добавлены следующие числовые признаки:

- max_power_squared: квадрат max_power;
- mileage_squared: квадрат mileage;
- power_per_liter: мощность на литр объёма двигателя;
- torque_rpm: произведение крутящего момента на обороты;
- log_km_driven: логарифм пробега;
- log_max_power: логарифм мощности.

После изучения распределений km_driven ограничен сверху 99-м перцентилем train. Та же граница применена к test. Строки с большим пробегом сохранены.

На обновлённых признаках повторно выполнен подбор alpha для Ridge. Лучшим снова оказалось значение 1000.

Получены следующие результаты:

| Выборка | R² | MSE |
|---|---:|---:|
| Train | 0,9009 | 2,8397e10 |
| Test | 0,9108 | 5,1271e10 |

После Feature Engineering модель объясняет около 91% разброса цены на test. Среднеквадратичная ошибка снизилась примерно на 60%.

## 5. Бизнес-метрики

Первая метрика считает долю прогнозов, отличающихся от реальной цены не более чем на 10%.

Вторая метрика считает долю прогнозов, попавших в денежные допуски: недооценка не более 50 000 и переоценка не более 100 000. Допуски задаются параметрами функции. Для недооценки установлен более строгий допуск. Значения измеряются в единицах selling_price.

Результаты на test:

| Модель | Ошибка не более 10% | Денежные допуски |
|---|---:|---:|
| LinearRegression | 24,2% | 37,0% |
| Lasso | 24,2% | 37,0% |
| Lasso с подбором параметров | 24,0% | 37,2% |
| ElasticNet с подбором параметров | 24,0% | 37,2% |
| L0 | 24,2% | 36,6% |
| Ridge с категориальными признаками | 31,1% | 45,6% |
| Ridge после FE | 35,6% | 54,0% |

Лучше всех справилась Ridge после Feature Engineering. У 35,6% предсказаний ошибка не превышает 10%. По денежной метрике 54% прогнозов уложились в заданные допуски.

## 6. Сохранение модели

Подготовка исходных данных, создание новых признаков, OHE, скейлер и лучшая Ridge объединены в общий пайплайн.

Пайплайн сохранён в model.pickle через cloudpickle. Вместе с ним сохраняются медианы для заполнения пропусков, граница ограничения пробега и правила выделения модели автомобиля.

После загрузки метод predict принимает DataFrame с исходными признаками. selling_price для предсказания не требуется.

## Что дало наибольший прирост

Среди сравниваемых этапов наибольший прирост R² дало добавление категориальных признаков: с 0,6007 до 0,7761.

Feature Engineering еще повысил R² с 0,7761 до 0,9108. Доля прогнозов с ошибкой не более 10% выросла с 31,1% до 35,6%, а денежная метрика с 45,6% до 54,0%.


## Что не получилось и почему

Стандартизация не улучшила обычную линейную регрессию, поскольку изменение масштаба признаков компенсируется изменением коэффициентов.

Lasso, ElasticNet и L0 не повысили качество на числовых признаках. Прирост появился после добавления категориальных и новых признаков.

Несмотря на высокий R² последней модели, большинство прогнозов всё ещё отличаются от реальной цены более чем на 10%.


## 7. Приложение Streamlit

Запуск из корня проекта в подготовленном окружении:

```bash
.venv/bin/python -m streamlit run app.py
```

Три вкладки показывают главное из уже выполненной работы: EDA, прогноз по CSV и 20 самых больших по модулю весов Ridge. В EDA взяты три сохранённых рисунка из `notebook.ipynb`: гистограммы числовых признаков, тепловая карта PhiK и pairplot по train. Новые эксперименты не запускаются.

Для прогноза скачайте пример из пяти машин и загрузите свой CSV в UTF-8 с запятыми. Нужны столбцы:

```text
name,year,km_driven,fuel,seller_type,transmission,owner,mileage,engine,max_power,torque,seats
```

Сохраняйте исходные строки с единицами, например `1248 CC` и `190Nm@ 2000rpm`. Числовые пропуски заполняет сохранённая модель. Таблицу можно проверить и скачать с новым столбцом `predicted_selling_price`; все входные столбцы и порядок строк сохраняются. Если такой столбец уже есть, сначала переименуйте его. Рисунки в `assets/`, пример в `data/example_cars.csv` и модель доступны локально, загрузка данных из сети не нужна.

Вкладки и готовый пример упрощают работу с несколькими машинами сразу, но для одной машины форма была бы удобнее CSV. Тепловая карта хорошо выделяет сильные связи, хотя PhiK не показывает направление и причинность. На гистограммах видны длинные хвосты, но редкие большие значения сжимают основную массу наблюдений, а подписи на общем рисунке мелкие. Следующее улучшение: возможность отдельно увеличить выбранную гистограмму.

Веса относятся к стандартизованным признакам, а не к их исходным единицам. Качество из ноутбука не гарантирует точную цену отдельной машины на сегодняшнем рынке; неизвестные категории и редкие автомобили могут давать менее надёжный прогноз. Единицы цены совпадают с исходным `selling_price`, отрицательные прогнозы линейной модели сохраняются без обрезки.
